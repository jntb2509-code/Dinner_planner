# נכסי המותג

`logo-mark.svg` — הסימן בלבד. משמש בכותרת המסכים הפנימיים.
`logo-full.svg` — הסימן והשם. משמש בעמוד הכניסה בלבד.
`../src/app/icon.svg` — אייקון הלשונית. גרסה מפושטת במכוון: טבעת
האנשים נמרחת מתחת ל-40px, ולכן שם נשאר רק המשושה עם הסיר.

> **הסימנים כאן הם שחזור זמני.** קובצי המקור לא הגיעו לסביבת הפיתוח,
> אז הם צוירו מחדש לפי העיצוב המקורי. כשהמקור יגיע — יש להחליף את שני
> הקבצים, וזה כל מה שנדרש.
